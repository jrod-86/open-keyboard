# Open Keyboard sticker store

`catalog.json` lists the sticker packs shown in Open Keyboard's sticker store. Every pack here must
be under a licence that allows redistribution (CC0, CC-BY, Apache-2.0, MIT...), with credit given in
the catalog.

| Pack | Artist | Licence | Source |
| --- | --- | --- | --- |
| Gopher Gang, Goroutines | Maria Letta | CC0-1.0 | https://github.com/MariaLetta/free-gophers-pack |
| Gopher Adventures | Egon Elbre | CC0-1.0 | https://github.com/egonelbre/gophers |
| Ferris the Crab | Karen Rustad Tölva | CC0-1.0 | https://rustacean.net/ |

The Go gopher was designed by Renee French and is licensed CC BY 4.0.

To add a pack: add a zip of PNG/GIF/WebP pictures, a 128 px icon and an entry in `catalog.json`.
